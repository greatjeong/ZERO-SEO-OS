# 통합 화면 실제 앱 반영 · 2026-11-23

마지막 private vision Site 소스 0c4c7ef3faca2fd4a6b0c7c67e75e5aab19f4c52를 복원해 기존 실제 React/FastAPI 앱에 통합. Site와 Railway를 별도 최종 버전처럼 유지해 혼동시킨 문제를 수정한다. 기존 private Site는 과거 시뮬레이션으로 보존하고 실제 운영 수정은 GitHub 앱을 기준으로 한다.

## 포함
- 통합 관리에 작업별 이동 카드, 12단계·48개 가이드와 단계별 진행 상태.
- 가이드 목표/준비물/클릭 경로/실습 순서/예시/오류 도움말/완료 확인/공식 출처. 복원된 가이드 전체를 최신 실사 검증했다고 주장하지 않음. 키워드 선별 내용은 최신 승인 기준으로 보정.
- 사이트 연결·키워드·원본 글·PBN·백링크·발행 색인·통계 메뉴. 기존 로그인/CSRF/사이트와 원본 글 로직 유지. 기존 사이트·키워드·초안 기록 삭제/자동 가져오기 없음.
- 키워드 6단계 이동 버튼은 기존 실제 검색/RSS/키워드 DB 영역을 연결. 시뮬레이션 fetch 어댑터는 복사하지 않음. SerpApi와 검색량 공급원/AI 생성은 별도 준비 상태.
- 새로운 hub_records 테이블은 기존 테이블과 분리. owner 인증, 쓰기 Origin/CSRF, revision 충돌 검사. 가이드 완료는 확인 두 개를 요구. 원격 사이트·백링크·색인 실행 없음.
- PBN/백링크/색인은 설정·수동 기록만 저장. 통계는 실제 측정 미연결 표시.
- 가이드/설정 데이터 JSON은 각 영역에서 별도 내보내기. 기존 v1/v2 workspace 백업은 그대로 유지하며 신규 기록은 포함하지 않음. 이전 브라우저의 진행 기록은 자동 이전하지 않음.

## 마지막 승인 화면 보존 수정

사용자가 마지막 승인한 네이비 대시보드와 달라졌다고 정정. 앞 통합은 기능·가이드 카탈로그를 옮기면서 UI를 재구성한 오류였다. 이후의 최우선 화면 기준은 vision Site 0c4c7ef의 원본 shell/style.css/renew.css/서체/아이콘이다. 별도 디자인 재구성은 하지 않는다.

- 원본 WORKSPACE / AUTOMATION STUDIO / 12-STEP JOURNEY, 상단 헤더·성장 로드맵 제목·안내, 네이비 hero·진행률·지표, 자동화 작업실 7개 카드, 12단계48개 카드 구조를 실제 React 앱으로 이전.
- 실습 가이드는 원본 모달·클릭 경로·순서·문제 해결·완료 확인·메모 배치를 적용. PBN/백링크/색인/통계도 원본 작업 패널 구조·스타일 사용.

## 저장 후 새로고침 시 유실 신고 수정
사용자가 완료 확인/메모 저장 후 새로고침 시 유실을 신고. 확인하고 완료하기가 클라이언트 상태만 변경하고 별도 기록 서버 저장을 요구하는 혼동 지점 확인. 실제 사용자 클릭 버튼/PUT 성공 여부는 직접 관찰하지 못했으므로 운영 DB 유실 원인으로 단정하지 않는다.
- 완료 버튼에서 최신 체크·메모·상태를 함께 PUT. React 상태 반영 전의 오래된 입력을 보내지 않도록 제출값을 명시 전달.
- 완료 버튼과 수동 저장 모두 PUT 후 GET 재조회로 revision과 전체 제출 내용을 대조한 뒤 저장 완료 표시. 재조회 불일치/실패 시 입력·미저장 상태 보존, 성공 표시 금지.
