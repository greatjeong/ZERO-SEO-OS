# 원본 글 작성: 참고 글 수집·관찰·목차·편집 첫 구현

2026-11-14 KST. 사용자는 발굴 키워드의 상위 티스토리·워드프레스를 참고해 구조를 분석하고 SEO·AEO·GEO 원본 글을 만든 뒤 PBN·백링크로 연결하는 방향을 승인했다. ‘승리 공식’이나 순위 보장이 아니라 관찰한 자료를 작성 기준으로 사용한다. 통합 관리 내부 기능이며 새 최상위 메뉴는 만들지 않는다. 기술 주 단계 A-02는 계속 진행 중이다.

## 이번 추가

- 통합 관리의 활성 작성 준비에서 ‘원본 글 작업 열기’. 해당 키워드·현재 대상 사이트의 적격 여부를 서버에서 확인하고 문서 작업 공간을 idempotent하게 연다.
- 최신 키워드 검색 근거에서 이미 티스토리/WP로 확인된 참고 글만 제시한다. 양쪽 엔진에서 같은 URL이면 중복을 줄이고 엔진·영역 내 번호 근거를 유지한다. 임의 URL 입력·네이버 블로그는 이번 수집 대상이 아니다.
- 선택한 최대3개 글을 익명 공개 HTTPS로 읽는다. 기존 DNS 검증·고정IP·크기/시간 제한·리다이렉트/인증 없음 GET 코어를 재사용한다. 본문은 article/알려진 본문 class 영역만 추출하며 메뉴/스크립트/푸터 등을 제외한다. 글마다 최대12000자 일부와 소제목·확인일·잘린 여부를 보관한다. 전체 사이트/모든 테마에서의 본문 인식을 보장하지 않는다. 구조 미인식·차단·연결 실패는 미확인으로 남긴다.
- 수집 자료의 소제목 빈도, 질문·절차·조건 표현 유무를 규칙으로 관찰한다. 순위 인과 분석/검색 의도 AI 추론/자동 팩트체크가 아니다. 목차는 핵심 답변→절차→조건/예외→FAQ→출처의 **편집용 출발 템플릿**이며 고유한 검색의도별 AI 목차는 아직 아니다. 직접 수정할 수 있다.
- SEO(의도·제목/소제목·정보 충족), AEO(근거 있는 답/절차), GEO(공식 출처·확인시점·미확인 구분) 작성 지침과 참고 자료를 구조화한 brief를 제공한다. 참고 웹문서 안의 명령을 데이터로 취급하도록 명시한다. 모델에 도구 실행 권한을 주지 않는다.
- 제목/Markdown 본문/목차 직접 편집, CAS revision 저장, 별도 append-only 버전 이력 조회. 참고 글 재수집은 기존 본문·편집 목차를 자동 교체하지 않고 검토 완료만 해제한다. 저장 충돌 시 화면 편집 유지. 본문 미저장 상태에서 참고 글 재수집/AI 생성은 비활성화한다. 다른 작업 열기/로그아웃/브라우저 떠나기 시 미저장 글 보호.
- 사실·출처·원본성·구조 체크와 메모를 본인 수동 검토 기록으로 저장. 체크는 자동 검증/품질 인증/노출 보장이 아니다. 다음 편집은 검토를 해제한다. 공백 제외 글자 수를 표시하지만 임의 최소분량·점수 기준을 강제하지 않는다.

## 실제 AI 연결 상태 — 과장 금지

`Authoring`의 generator 인터페이스와 generate API의 입력/응답 검증·버전 보존을 준비했다. **현재 중앙 앱 팩토리는 generator=None**이며 실제 공급자 어댑터·모델 선택·API 키 설정 UI는 아직 없다. 단순히 API 키를 넣으면 즉시 생성되는 완성 상태가 아니다. 생성 버튼은 ‘모델 미연결’로 비활성, 직접 요청하면503이며 글을 만들어 넣지 않는다. 테스트의 lambda generator는 모의이며 실제 모델 호출 증거가 아니다.

다음 AI 연결 작업에서 사용자와 모델/비용·분량/스타일 등 필요한 사항을 정하고 실제 공급자 코드를 붙인다. 공식 출처 탐색·팩트체크 자동화, 문장 유사도 검사, 자동 이미지/메타/스키마, 실제 WordPress 원본 초안 저장·발행 및 PBN·백링크 실행은 아직 연결하지 않았다. 기존737/738 테스트 초안 도구를 실제 원본글 저장기로 재사용하지 않는다.

## 데이터 보존

새 `original_article_documents`, `original_article_versions` 테이블에 문서·각버전 스냅샷을 저장한다. 원래 키워드·준비 큐·workspace·.state·WordPress 이력은 보존한다. 기존 v1/v2 JSON·키워드bank export에는 이 문서 테이블이 포함되지 않으므로 운영 DB 백업 대상에 포함해야 한다. 이력은 읽기 전용이며 복원/자동 덮어쓰기 기능은 아직 아니다.

모든 문서 API는 소유자 세션, 쓰기 Origin/CSRF 보호. 기사 저장·수집은 기존 행을 지우지 않으며 충돌 시409. 실제 WordPress POST/공개 발행 없음. Markdown·참고 데이터는 React 텍스트로만 표시하고 수집 HTML/AI HTML을 실행하지 않는다.
