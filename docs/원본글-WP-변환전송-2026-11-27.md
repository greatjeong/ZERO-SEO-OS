# 원본 글 → WordPress 초안 연결 보완 · 2026-11-27

사용자: 독립 개발 가능한 부분은 바로 계속 개발. 기존 승인 화면/메뉴/데이터 유지, 실제 외부 연결 시험은 추후 통합 진행. A-02 사용 흐름 보완 및 PHASE C의 원본 초안 전달 선행 구현이며 주 단계 완료 선언은 하지 않는다.

## 이번 변경

- 저장된 원본 Markdown을 제목·문단·목록·인용·코드·단순 표·강조·HTTP(S) 링크를 지원하는 제한된 HTML로 변환한다. 원시 HTML은 문자로 표시하고 이미지/스크립트/임베드를 실행하지 않는다. 전체 Markdown 표준 구현은 아니다. 중첩 목록·복잡한 표·중첩 인라인 표기는 제한된다.
- 원본 글 편집기에 **워드프레스 초안 미리보기**, 격리 iframe, **워드프레스용 본문 HTML 내보내기**를 추가했다. 서버 저장 버전과 화면 버전이 다르면 표시를 중단하며, 미저장 원고의 변환/내보내기를 차단한다. 미리보기는 문서나 외부 사이트를 변경하지 않는다.
- 로그인 보호 GET `/api/authoring/{key}/wordpress-preview` 추가. 기존 문서·버전 테이블 구조는 변경하지 않는다.
- 별도 주입용 `WordPressArticleTransport`를 구현했다. 기존 암호화 보관소와 DNS 검증/HTTPS 고정 연결 코어를 재사용한다. 사이트 일치, 작성 권한, 인증 세대 변경, ID 형식을 확인한다. POST는 draft만 전송하고 자동 재시도하지 않는다. 알려진 ID 조회는 GET만 사용한다.
- 기존 `ArticleDrafts`의 전송 전 영속 intent, ID 보존, 결과 불확실 시 재생성 차단과 결합해 시험했다. 실제 운영 transport는 아직 설치하지 않았으며 운영 전송 버튼/API도 추가하지 않았다. 미리보기가 실제 WP 테마와 같은 화면을 보장하지 않는다.

## 검증

변환/HTML 비실행/링크 검사/권한/사이트 변경/응답 누락/GET 재조회 시험과 기존 회귀 검사를 수행했다. 모의 transport 연결 시험에서 POST 성공 후 GET timeout → ID 92 보존 → 같은 문서 재요청 시 POST 없음 → GET 재조회 성공을 확인했다. 글 92는 모의 ID이며 실제 글이 아니다.

UI 테스트는 미리보기가 전송 API를 호출하지 않는지, iframe 격리, 편집본 유지와 미저장 내보내기 차단을 검사한다. 실제 WP 요청·AI·유료 API 사용은 하지 않았다.

## 남은 작업

- 운영 사이트 인증 등록 후 원본 초안 실제 전송/본문 확인. 현재 연결은 계속 꺼져 있다.
- 변환된 본문과 WP 서버 저장 원문 비교, 원본 수정 시 기존 WP 글 업데이트 정책.
- 공개/예약 발행·취소/예약 변경 및 실제 작업 worker.
- 실제 AI/검색량 공급자 연결, PBN/백링크 실행, 전체 PostgreSQL 복구 검증.

사용자 확인 위치: 적격 키워드의 작성 준비 → 원본 글 작성 → 원고 저장 → **워드프레스 초안 미리보기**. 적격 데이터가 아직 없으면 외부 연결 시험 때 함께 확인한다.

검증 결과: 서버 전체180개 통과, 마지막 인증 경로 추가 후 관련18개 재통과. UI 전체51개 통과, TypeScript/Vite 빌드 및 diff 공백 검사 통과. 실제 운영 로그인 세션에서 새 미리보기 기능은 아직 검사하지 않았다.
