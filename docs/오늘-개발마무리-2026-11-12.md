## 종료 시 보관 대상

1. 앱에서 키워드·작업 기록 JSON을 내려받아 보관합니다. 이 문서 작성만으로 JSON 백업이 수행된 것은 아닙니다.
2. 사이트 이름·주소는 브라우저에 보관되며 JSON에 포함되지 않습니다.
3. `backend/.state`는 테스트 초안 중복 방지용 로컬 기록입니다. 기존 폴더를 유지합니다. Git에 포함하지 않습니다.
4. 앱 비밀번호는 Git·문서·브라우저 저장소에 넣지 않습니다. 서버 재실행 시 터미널에서 입력합니다. 채팅에 노출된 비밀번호는 폐기 대상입니다.
5. Git 커밋·푸시를 완료한 뒤 성공 결과를 확인합니다.
6. 화면 서버와 연결 서버의 터미널에서 각각 Ctrl+C로 종료합니다.

## Git 저장 상태

종료 준비 시 바탕화면 프로젝트의 main 브랜치와 변경 파일, GitHub 원격 저장소를 확인했습니다. 서버 상태 데이터와 Python 캐시는 Git에서 제외됨을 확인했습니다.

이 작업에서 바탕화면 폴더 쓰기·네트워크 권한이 허용되지 않아 에이전트가 프로젝트 복사·커밋·푸시를 실행하지 않았습니다. 아래 기록 묶음을 프로젝트에 복사한 뒤 사용자가 명령을 실행해야 합니다. 성공 출력이 오기 전에는 GitHub 저장 완료로 표시하지 않습니다.

프로젝트 루트에서 실행할 명령:

```powershell
git add frontend/src/App.tsx frontend/src/App.css frontend/src/WordPressSites.tsx frontend/vite.config.ts backend docs AGENTS.md
git commit -m "Save ZERO SEO OS v0.2.2 and roadmap"
git push
git status --short
```

오류가 나오면 강제 푸시나 기록 초기화를 하지 않고 결과부터 확인합니다.
