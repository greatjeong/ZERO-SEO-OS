# Windows 연결 서버 실행창 종료 대응

2026-11-13. A-03 실행 도구 개선 및 A-04 검증 준비. 기술 주 단계는 A-02 진행 중 유지.

사용자가 A-1 https://a.webcreatorlabs.com 연결·테스트 초안 저장을 승인했으나 로컬 연결 서버 창이 입력 후 닫혔다고 보고했다. 실제 오류는 아직 확인하지 못했다. Python 미설치·버전, server.py 문법·인코딩, 포트 충돌 등 원인을 확정하지 않는다.

Start-Connector.ps1은 인증정보 입력 전에 Python 3.11 이상을 확인하고 python 실행 불가 시 py -3를 시도한다. 서버 파일 존재와 UTF-8 문법을 확인한 뒤 실행하며 비정상 종료를 표시한다. 종료·실패 후 환경변수를 복원하고 사용자 Enter 입력까지 창을 유지한다. Start-Connector.cmd는 동일 폴더의 스크립트를 -NoExit로 호출해 PowerShell 구문 오류나 실행 정책 차단도 창에 남긴다. 실행 정책은 변경하거나 우회하지 않는다. 인증정보 저장·로그 기록, 기존 .state 변경은 추가하지 않았다.

사용 방법: 기존 backend 폴더에 두 실행 파일만 교체·추가하고 Start-Connector.cmd를 더블클릭한다. 정상 시작 후 창은 그대로 유지하고 대시보드에서 연결 확인을 누른다. 오류가 나오면 인증정보를 가린 오류 부분만 확인한다.

검증: git diff 공백 검사 및 Python preflight 대상 UTF-8 문법 확인. 이 개발 환경에는 PowerShell/Windows가 없어 실제 Windows 실행 검증은 미완료다. 사용자의 PC 오류 확인이 다음 작업이며 이번 수정만으로 연결 성공이나 초안 저장 완료로 표시하지 않는다.
