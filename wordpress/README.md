# WordPress 소개 본문 · v0.1

사용자가 제공한 Home의 사용자 정의 HTML을 대체하기 위한 검토본. GeneratePress 부모 테마를 수정하지 않으며 별도 CSS 삭제/전역 숨김/JavaScript/외부 리소스 로딩 없음. 클래스 zintro/zi-* 범위 안에서만 스타일 적용. WordPress 관리자 HTML 권한/필터에 따라 style 태그 유지 여부를 실제 미리보기에서 확인한다.

## 범위

소개 본문: 중앙 히어로, 정직한 개발 상태, 비동작 App 화면 구성 예시, 4단계 흐름, 정확히 네 메뉴, FAQ. 기존 헤더·공지·푸터는 페이지 HTML 밖에 있으므로 이 파일만 교체해도 없어지지 않는다. header 구조를 확인한 뒤 따로 정리한다. 로그인/App은 disabled이고 실제 인증/회원가입/발행 없음. 참조 사이트의 이미지·로고·문구·코드를 복사하지 않았다. 실제 참조 폰트는 미확인이며 기존 폰트 상속/시스템 대체에 Pretendard 우선순위만 둔다.

## 적용

기존 페이지 본문은 원본 복사/리비전으로 보존한다. 먼저 별도 초안 페이지의 사용자 정의 HTML 블록에 introduction-block.html 전체 삽입 후 미리보기. 실제 홈 교체는 검토 뒤 진행. 기존 컨테이너 폭·테마 여백·커스텀 CSS가 외부에서 제한할 수 있으므로 사이트에서 확인 필요. 로컬 미리보기는 테마 밖 본문만 확인하는 것이며 WP 적용 완료가 아니다.

## 최신 사용자 확정

growwithzero.com(Cloudways WordPress)을 소개 홈페이지로 재구성. 기존 화면을 보존·재사용하는 제안보다 새 화면 제작이 최신 지시. 네이비 #071226/보라 #7C3AED 유지. 브랜드명은 임시이며 향후 변경. 소개에서 로그인 후 자동 App 이동 금지: 소개로 복귀 후 상단 App 클릭. App은 통합 관리/키워드 발굴/PBN 세팅/백링크 세팅 네 페이지. 2~4에서 준비하고 통합 관리에서 글 작성/WP/PBN/백링크를 실행. SNS 추후. 키워드 로직 임의 개발 보류. Render 최소 유료 운영은 합의, 카드 등록은 다음 날로 보류. Cloudways 사이트 실제 편집 접근 없음, 사용자 화면/제공 본문만 확인.
